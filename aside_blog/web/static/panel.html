네이버 블로그 올리기

글 목록

이렇게 써요

  1. 처음 한 번: 대시보드 ④ 에서 네이버 계정을 추가하고 「로그인 창 열기」 → 왼쪽 창에서 네이버 로그인(로그인 상태 유지 체크).
  2. 글을 고르고 「미리 채워 보기」 — 왼쪽 창에 제목·본문·그림·발행 설정까지 채우고 발행 직전에서 멈춰요. 괜찮으면 직접 「발행」을 눌러도 돼요.
  3. 잘 들어가면 다음부터는 「지금 발행」 또는 「예약」. 예약은 네이버 발행 창의 예약으로 넘겨서 PC 를 꺼도 발행돼요.
  4. 직접 글쓰기 창을 열어 두었다면: 「현재 탭 선택하기」 → 그 창 고르기 → 「선택된 글쓰기창에 넣기」 (영상 속 방법과 같아요).
  5. 네이버 화면이 바뀌어 버튼을 못 찾으면: 대시보드 ④ 「글쓰기 화면 구조 확인」 결과를 담당자에게 보내 주세요.
